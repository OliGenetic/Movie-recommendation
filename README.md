# Рекомендация фильмов FilmStart

**FilmStart** — это умный Telegram-бот, который помогает определиться с выбором фильма на вечер. 

Бот использует актуальную базу данных **The Movie Database (TMDB)** и учитывает не только стандартные параметры (год, жанр), но и ваше настроение, тематику персонажей и даже сезонность.

## Особенности бота

*   **Динамический опрос:** бот адаптируется под ваш выбор. Например, при выборе «аниме» он пропускает вопрос о стране производства (так как они предопределены), а вопрос о длительности задает только для полнометражных фильмов.
*   **Учет настроения:** Сопоставляет ваше настроение с жанрами TMDB (например, «Взбодриться» -> Боевики/Триллеры).
*   **Умный поиск по описанию:** TMDB — международная база, и иногда у фильма нет **русского описания**. В таких случаях бот автоматически делает дополнительный запрос, чтобы получить **английское описание**. Если нет и его — выводится заглушка.
*   **Сезонные подборки:** отдельная кнопка для поиска новогодних и рождественских фильмов (по ключевым словам TMDB).
*   **Пагинация:** возможность листать результаты («Показать ещё») без потери текущих фильтров.
*   **Удобный интерфейс:** сочетание Inline-кнопок для опроса и постоянной Reply-клавиатуры (внизу экрана) для быстрого доступа к функциям.

## Технологический стек

Проект написан на **Python** с использованием менеджера пакетов **uv**.

*   `pyTelegramBotAPI` (telebot) — синхронная работа с Telegram API.
*   `requests` — запросы к внешнему API (TMDB).
*   `python-dotenv` — безопасное хранение токенов.
*   `FastAPI` + `uvicorn` — легкий веб-сервер, который работает параллельно с ботом в фоновом потоке. Это необходимо для корректной работы на облачном хостинге.

**Внешний API:** [The Movie Database (TMDB) API v3](https://www.themoviedb.org/).

## ☁️ Хостинг и поддержание активности

Проект развернут на платформе **Render** (бесплатный тариф Web Service).
Платформа Render имеет особенность: если к сервису нет входящих HTTP-запросов более 15 минут, он «засыпает» для экономии ресурсов. Так как Telegram-бот использует `long polling` (сам отправляет запросы), Render не видит активности и усыпляет его.

**Как решена проблема сна:**

1. В коде бота запущен FastAPI с эндпоинтом `/health`, который возвращает `{"status": "ok"}`.
2. Сервис **cron-job.org** настроен на отправку HTTP GET-запроса на `https://...onrender.com/health` каждые 5 минут.
3. Благодаря этим «пингам» Render видит входящий трафик и поддерживает работу сервиса 24/7. Бот всегда онлайн и отвечает мгновенно!

## Структура проекта

Проект разделен на логические модули для удобства поддержки и масштабирования:

```
movie-recommendation/
│
├── .gitignore            # Исключения для Git
├── pyproject.toml        # Конфигурация проекта и зависимости (uv)
├── uv.lock               # Файл блокировки точных версий зависимостей
├── render.yaml           # Файл для автоматической настройки Render (сервис, поддерживающий чат-бота)
├── README.md             # Документация проекта
│
├── config.py             # Чтение токенов из .env, где они хранятся
├── bot.py                # Главный файл запуска, обработчики команд и состояний
├── keyboards.py          # Генерация Inline и Reply клавиатуры.
└── tmdb_api.py           # Функции для работы с API (поиск, случайный фильм, подборки).
```

## Как создать своего такого бота

1. **Ключи**: Получите `BOT_TOKEN` у `@BotFather` и `TMDB_API_KEY` на сайте [themoviedb.org](https://www.themoviedb.org/).

2. **Файл `.env`**: Создайте в корне проекта файл `.env`:
   ```
   BOT_TOKEN=ваш_токен_телеграм
   TMDB_API_KEY=ваш_ключ_tmdb
   ```

3. **Установка зависимостей**
Убедитесь, что у вас установлен uv. Затем выполните в терминале:

```
uv sync
```
Эта команда автоматически создаст виртуальное окружение и установит все зависимости точно по файлу `uv.lock`.

4. **Запуск бота локально**

Запустите бота с помощью команды:
```
uv run bot.py
```

После появления в консоли сообщения 
```
Бот запущен и готов к работе!
```
найдите Вашего бота в Telegram и отправьте ему команду `/start`.

5. **Деплой:** Загрузите код на GitHub, создайте Web Service на Render и добавьте переменные окружения (`BOT_TOKEN`, `TMDB_API_KEY`). 
Установите пинги через `cron-job.org` на Ваш `/health` эндпоинт!
