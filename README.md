# Рекомендация фильмов FilmStart

Телеграм-бот для подбора фильмов, который учитывает не только жанр и год, но и ваше текущее настроение, любимых персонажей и страну производства. 

Бот использует актуальную базу данных фильмов от **The Movie Database (TMDB)** и современный менеджер пакетов **uv**.

## Основные возможности

*   **Пошаговый подбор:** Удобный диалог с использованием инлайн-кнопок (формат ➡️ настроение ➡️ год ➡️ страна ➡️ сюжет ➡️ персонажи ➡️ рейтинг ➡️ длительность).
*   **Учет настроения:** Бот подбирает жанры в зависимости от выбранного настроения (например, «Расслабиться» ➡️ Комедии, «Пощекотать нервы» ➡️ Триллеры/Ужасы).
*   **Продвинутая фильтрация:** Поиск по ключевым словам (например, «по играм», «про роботов», «про вампиров»), стране, году и рейтингу.
*   **Случайный фильм:** Кнопка для быстрого поиска случайного качественного фильма.
*   **Красивая выдача:** Бот отправляет постер, название, год, рейтинг и краткое описание фильма.

## Технологический стек

*   **Язык:** Python 3.11+
*   **Библиотеки:** 
    *   `pyTelegramBotAPI` (telebot) — работа с Telegram API.
    *   `requests` — HTTP-запросы к TMDB API.
    *   `python-dotenv` — безопасное хранение токенов.
    *   `fastapi` + `uvicorn` — для health-check на хостинге.
*   **Менеджер пакетов:** `uv` (для быстрой установки зависимостей и изоляции окружения).
*   **Внешний API:** [The Movie Database (TMDB) API v3](https://www.themoviedb.org/).

## Установка и запуск нового бота
1. Подготовка ключей
Вам понадобятся два ключа:

`BOT_TOKEN:` Получите у @BotFather в Telegram.

`TMDB_API_KEY:` Зарегистрируйтесь на themoviedb.org, перейдите в Settings -> API и запросите ключ (достаточно короткого API Key v3).

Создайте в корне проекта файл .env и добавьте туда ваши ключи:

```
BOT_TOKEN=ваш_токен_от_BotFather
TMDB_API_KEY=ваш_ключ_от_TMDB
```

2. Установка зависимостей
Убедитесь, что у вас установлен uv. Затем выполните в терминале:

```
uv sync
```
Эта команда автоматически создаст виртуальное окружение и установит все зависимости точно по файлу uv.lock.

3. Запуск бота

Запустите бота с помощью команды:
```
uv run bot.py
```

После появления в консоли сообщения 
```
Бот запущен и готов к работе!
```
найдите Вашего бота в Telegram и отправьте ему команду /start.

## Как работает 

- State Machine: в `bot.py` используется словарь `user_states`, который хранит `chat_id` пользователя и текущий шаг диалога (year, genre и т.д.). При нажатии на инлайн-кнопку состояние обновляется.

- Обработка ошибок: в `tmdb_api.py` реализована проверка `response.status_code`. Если фильмов не найдено, бот вежливо сообщает об этом пользователю.

- Безопасность: токены не захардкожены в коде, а считываются через `os.getenv()`.

## Хостинг и поддержание активности
Бот развёрнут на платформе **Render** (бесплатный тариф Web Service).

* **Render** автоматически «усыпляет» бесплатные сервисы после 15 минут без входящего трафика, чтобы экономить ресурсы. При следующем запросе сервис «просыпается».

* **UptimeRobot** настроен на периодическую отправку HTTP-запросов на health-check эндпоинт бота (например, `/health`). Это создаёт входящий трафик и предотвращает засыпание сервиса, обеспечивая его постоянную доступность.
